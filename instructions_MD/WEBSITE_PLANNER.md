# Racked View Website Planner

This roadmap covers the public Racked View marketing website only. The authenticated rack-management application, Supabase data model, mobile app, subscriptions, and QR product flows are intentionally deferred until the website is ready to convert and validate demand.

## Goal

Launch a clear, credible public site for Racked View that explains the product promise:

> Build the rack. Photograph the rack. Scan the rack.

Primary audiences: IT departments, managed service providers, schools, hospitals, and multi-site businesses that maintain communication or server racks.

## Phase 1 - Core Marketing Page

- [x] Establish Racked View branding, product statement, and logo usage.
- [x] Create a responsive hero with a direct path into the live rack builder.
- [x] Expand the landing page into a complete product story: problem, workflow, key capabilities, and audience fit.
- [ ] Add clear product screenshots/illustrations that show layout, real-world photo documentation, and QR rack access.
- [ ] Add a focused CTA path for trying the rack builder and joining the launch list.
- [ ] Verify desktop and mobile presentation with browser screenshots.

## Phase 2 - Trust And Conversion

- [ ] Add privacy policy and terms links before collecting contact information.
- [ ] Add a privacy-conscious waitlist/contact capture flow backed by Supabase.
- [ ] Add success/error states, abuse protection, and a consent notice to the capture flow.
- [ ] Add a concise FAQ covering use cases, supported teams, and launch availability.
- [ ] Add SEO metadata, social preview image, favicon, robots.txt, and sitemap.xml.

## Phase 3 - Public Product Pages

- [ ] Create a product page for Rack Builder.
- [ ] Create a product page for Photo Documentation.
- [ ] Create a product page for secure QR rack sharing.
- [ ] Create an industry/use-case page for MSPs, IT teams, schools, hospitals, and multi-site organisations.
- [ ] Publish a contact/support route.

## Phase 4 - Launch Readiness

- [ ] Configure the production domain and HTTPS hosting.
- [ ] Configure a transactional email provider for verified waitlist/account emails.
- [ ] Add privacy-respecting analytics with cookie consent where required.
- [ ] Test forms, navigation, mobile breakpoints, keyboard navigation, and performance.
- [ ] Review content, legal links, and contact details before launch.

## Deferred Product Work

- [ ] Supabase user, organisation, role, and row-level security model.
- [ ] Persistent cloud racks, sites, locations, devices, and activity history.
- [ ] Rack photo uploads and digital/photo comparison.
- [ ] QR generation, public rack view, and QR access modes.
- [ ] Billing/subscriptions.
- [ ] Native iOS and Android applications.
